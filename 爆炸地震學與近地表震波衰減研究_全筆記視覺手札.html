STEP 01｜線索起點：接收跨介質訊號，並用 Z・R・T 三軸分離波型

第一步：先把地震儀收到的混雜波動「拆解成三個正交方向」

法醫地震學透過地震儀（Seismogram）、次聲波／紅外線聲波（Infrasound / Acoustogram）、水聲感測器（Hydroacoustic）與衛星訊號，監測地下核試爆、礦場爆破、礦坑坍陷與岩爆（Mine collapse & rock bursts）、火山活動、大氣爆炸、機械振動及恐怖攻擊。在判斷事件性質前，必須先認識兩種基本體波，並把波形轉到 Z・R・T 座標系。

P 波（縱波 / 壓縮波） 約 6.5 km/s

質點運動方向與波行進方向相同（平行），造成岩石前後「壓縮 ⇄ 伸張」。波速最快，最先抵達測站。

S 波（橫波 / 剪切波） 約 4.0 km/s

質點運動方向與波行進方向垂直，需要岩石發生錯動、扭轉或摩擦（剪力）才能激發。

三個方向的定義與主要地震波型（Z・R・T 三分量系統）

將測站旋轉至「震央 → 測站」連線座標後，壓縮波（P）與水平剪力波（SH/Love）就會自動分家：

分量 代號 方向定義 主要記錄波型
垂直向 Z 垂直地表（上下） P 波、SV 波、雷利波
徑向 R 沿震央到測站連線（前後推拉） P 波、SV 波、雷利波
切向 T 水平垂直連線（左右搖晃） SH 波、洛夫波
銜接下一步：把波型分進 Z・R・T 三軸後，我們就能直接比較「壓縮波（Z/R）」與「剪力波（T）」的強弱，進入第二步分辨天然地震與人為爆炸！
STEP 02｜核心鑑識：抓出震源機制與波型差異（Kim, 2017 五大判準）

第二步：如何判定這起事件是「天然地震」還是「地下核試爆」？

天然地震是斷層面的雙力偶錯動（DC，4個力平衡不旋轉），產生強烈剪力波；而地下核試爆如同氣球在地下瞬間膨脹，屬於各向同性純體積壓縮（ISO），幾乎不直接激發 S 波與表面波。透過以下兩大關鍵工具即可一舉破案：

2017/09/03 北韓核試（UC Berkeley 反演，深度 1 km，mb 6.3 / Mw 5.23）：
聯合 BJT、HIA、MDJ、INCN 長週期波形（0.02–0.05 Hz）與 34 個遠震 P 波初動極性，反演出 ISO（各向同性爆炸成分）高達 42%、DC 雙力偶 34%、CLVD 24%，遠離純天然地震線。
為什麼核試爆的表面波（Love & Rayleigh wave）較弱？
洛夫波由水平剪力波干涉形成，雷利波亦高度依賴 S 波與地表耦合。核爆缺乏斷層錯動剪力、原始 S 波極弱，連帶導致表面波振幅偏小（這也是 mb vs. Ms 判別法的物理基礎）。

鑑識工具 B：大陸地殼導波（Lg）與高頻 Pg/Lg 頻譜比法

g = Granitic（花崗岩質大陸地殼）

Pg 是沿花崗岩大陸地殼直接傳播的壓縮波（第一聲巨響）；Lg 則是被困在花崗岩地殼與莫荷面（Moho）之間、多重全反射疊加的剪力波導（波速約 3.5 km/s，觀測距離 120–2000 km，如同地殼回音）。只要在高頻段（>5 Hz）計算 log(Pg/Lg)，數值高高在上的就是爆炸，貼近或低於 0 的就是天然地震！

STEP 03｜承上啟下：確認是爆炸後，先清洗數據才能算威力

第三步：扣除儀器響應、檢驗 SNR 與高斯濾波，還原真實地面振動

既然第二步已經抓出「這是人為爆炸」，接著我們要問：「爆炸威力到底有多大？」這需要量測地面實際的最大振動速度（PGV）。但地震儀存下來的原始數位訊號（count）混雜了儀器硬體偏差與環境雜訊，必須先經過以下三道清洗手續：

清洗手續 ②：訊噪比（SNR）與 P−1 秒緩衝區

計算「綠色訊號區 ÷ 灰色雜訊區」能量比（SNR < 2 或 3 則淘汰）。雜訊窗刻意只取到波抵達前 1 秒（P−1s），避免人工標記誤差把波頭算進雜訊裡。

以中心頻率 f0（如 3.5 Hz 或 5 Hz）為鐘形平滑篩子，讓離 f0 越遠的頻率平滑衰減，避免傳統方波陡切在波形前後產生多餘的假波紋（Ringing）。

STEP 04｜最終破案：量出真實 PGV → 代入衰減式 → 反推事件規模 ML

第四步：從「最大地動速度（PGV）」反推爆炸威力與 2014 高雄氣爆規模

經過第三步清洗後，我們終於能從乾淨的真實速度波形中量出峰值——也就是 PGV（Peak Ground Velocity，最大地動速度）。因為爆炸沒有斷層錯動面積可量，我們正是透過「PGV 隨距離 X 衰減的經驗公式」，把測站量到的真實 PGV 換算回震源的區域規模（ML）！

① 正向衰減關係式（已知規模 M，預測距離 X 的 PGV）
log(PGV) = a·log(X) + b·X + c·ML + d

利用台灣 TAIGER 岩盤炸測實驗（已知炸藥量），反演出近地表爆炸專用係數：a = −1.41, c = 1.16, d = −6.63（斜率比 1999 集集地震天然地震衰減式更陡）。

② 移項反推規模公式（量出真實 PGV → 算出 ML）
ML = [ log(PGV) − a·log(X) − b·X − d ] / c

遇到未知威力的事件時，只要代入各測站的距離 X 與真實 PGV，即可反推出事件規模——本研究藉此成功推估 2014 高雄氣爆規模為 ML = 2.38！

展開檢視：為何近地表爆炸衰減更快？＆ 影響爆炸能量轉換的五大因素・TAIGER 測線細節 ▾
一、為什麼近地表爆炸的 PGV 隨距離衰減比深層天然地震快得多？
  • 極淺層鬆軟介質吸收：近地表爆炸波沿風化層與土壤傳播，孔隙介質非彈性耗散極強（深層天然地震則走緻密高 Q 值岩層）。
  • 高頻能量易散射：爆炸集中於高頻波段（>5 Hz），短波長極易被地表裂隙與地形起伏散射衰減。
  • 多重潛波（Multiple Diving Waves）：極淺層陡峭速度梯度（1D Steep Velocity Gradient）使震波在淺部反覆折射彈跳（如 TAIGER 南北測線 Vred = 5.5 km/s 與 CHY031 極淺層強震紀錄），每次反射都損失大量能量。
  • 自由表面逸散：震源離地表極近，絕大部分能量直接衝出地表轉為光、熱、空氣聲波與圍岩破壞。
二、影響爆炸轉換為地震波能量的五大因素＆經驗公式對照：
① 炸藥當量（Yield）：愈大能量愈強（如 N3 750 kg vs. N3P 3000 kg）；② 爆炸深度：愈深轉換效能愈好；③ 井孔回填覆蓋：TAIGER 鑽井下炸藥後覆蓋角礫石封孔；④ 周遭介質特性：花崗岩、岩鹽傳導高，軟泥巴吸收能量；⑤ 耦合程度：貼合愈緊實能量愈完整，有空隙則能量消耗於空隙。傳統天然地震式包含 Joyner & Boore (1981)、Campbell (1981) 及 1999 集集地震 Liu & Tsai (2005)。
STEP 05｜故事收束：研究六大結論與聽講心得

第五步：總結與聽講心得

演講研究六大核心結論

  1. 2017 年北韓核試驗產生之雷利波在相近距離下的振幅衰減呈現明顯空間差異，可歸因於日本海下方地下構造的不均質性（高速散焦、低速聚焦）。
  2. 利用 TAIGER 計畫岩盤測站的地震波形資料，建立了首個適用於近地表爆炸事件之最大地動速度（PGV）衰減方程式。
  3. 西部平原地區所觀測到的 PGV 衰減特性與岩盤測站所呈現的衰減型態有顯著差異。
  4. 炸藥使用量與觀測所得區域規模（ML）的關係顯示各次爆破效率不同，推測與當地地質條件、耦合效果及實際引爆炸藥量有關。
  5. 透過所建立的衰減公式，成功推估出 2014 年高雄氣爆事件所對應之區域規模為 ML = 2.38。
  6. 發生於平原地區之近地表爆炸事件的衰減方程式，仍有待進一步建立。
